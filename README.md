# Library Management System

A simple Python-based Library Management System built using Object-Oriented Programming (OOP).

## Features

- Add new books
- Display all books
- Search books by Book ID
- Issue books
- Return books
- Delete one book
- Delete all books
- Update book details
- Display issued books
- Save issued books to a text file

## Concepts Used

- Python Classes and Objects
- Constructors (`__init__`)
- Lists
- Tuples
- Loops
- Conditional Statements
- Functions
- Linear Search
- File Handling

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed.
3. Run the Python file.
